## 🚀 Projeto em destaque

### ✈️ Sistema de Reservas de Voos

Aplicação full-stack para gerenciamento de reservas aéreas, construída como projeto de evolução contínua — migrei de uma abordagem inicial com JDBC direto para uma **arquitetura em camadas** completa.

**Backend**
- Java + Spring Boot
- PostgreSQL como banco de dados
- Arquitetura em camadas: `Controller → Service → Repository`
- Configuração de CORS para comunicação com o frontend
- Credenciais externalizadas via `application.properties`
- Build gerenciado com Maven

**Frontend**
- React + Vite
- Componentes funcionais, `useState`, `useEffect`, `fetch` para consumo da API
- CRUD completo: listagem, criação, edição e exclusão de registros

**O que aprendi construindo este projeto:**
- Migração de um padrão JDBC/MySQL direto para uma API REST em camadas
- Fundamentos de React na prática (componentes, estado, props, hooks)
- Integração frontend/backend com CORS e Vite dev server
- Resolução de conflitos de Git em fluxo de trabalho real (push/pull, merge commits)

📂 Acesse o código do projeto: [`/flight-reservation-system`](./flight-reservation-system)
